<p>Cloning saves rebuilding a sequence step by step. It is the quickest way to run a proven flow for a new segment, or to reuse a structure a colleague has already built.</p>

<h2 class="kb-sub">Clone the flow</h2>
<ol class="kb-steps">
  <li>
    <p>Click the <span class="kb-kbd">Flows</span> icon in the left sidebar.</p>
    <figure class="kb-figure" data-ph="Screenshot: the Flows icon">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/14c1c1c4-4a13-4a5a-b647-1b8804ecefde/action-626a9fac5bf0483b8f701b691c9261d9_8ec9655c178b47eb98045efc4a2665c7_text_export.jpeg" alt="The Flows icon in the left sidebar" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Opening Flows</figcaption>
    </figure>
  </li>
  <li>
    <p>If the flow belongs to a colleague, open the <span class="kb-kbd">User</span> dropdown to filter by their name.</p>
    <figure class="kb-figure" data-ph="Screenshot: the User dropdown">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/f15675ad-9d5e-48ac-a025-7f1d3a7dd2bc/action-77b9693096a94a52856292c566484565_0adba764bd034d6dbb34acb95384c2db_text_export.jpeg" alt="The User dropdown on the Flows page" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Filtering by user</figcaption>
    </figure>
  </li>
  <li>
    <p>Select the user name and click <span class="kb-kbd">Apply changes</span>.</p>
    <figure class="kb-figure" data-ph="Screenshot: applying the user filter">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/fc15e8f3-990c-4716-9df4-65960b7affc5/action-0d63605724d44393811d7e839da7940d_4f7f894b41884840aeed9c4cb45a013e_text_export.jpeg" alt="Applying the user filter" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Applying the filter</figcaption>
    </figure>
  </li>
  <li>
    <p>Select the flow you want to clone.</p>
    <figure class="kb-figure" data-ph="Screenshot: selecting the flow">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/817836d8-1045-479a-977a-b73bc0259563/action-c2ff0975e55b4cc8a16083d75d86f5de_489445bba0d045bcbf031aa99406488f_text_export.jpeg" alt="Selecting the flow to clone" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Choosing the flow</figcaption>
    </figure>
  </li>
  <li>
    <p>From the menu, click <span class="kb-kbd">Clone</span>.</p>
    <figure class="kb-figure" data-ph="Screenshot: the Clone option">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/d91df546-15eb-4597-8582-504f6c19b3ca/action-6ef79518d7ca45249684788b4a5602c3_c59c3e73309b4525942c227392eca3ab_text_export.jpeg" alt="The Clone option in the flow menu" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Cloning the flow</figcaption>
    </figure>
  </li>
  <li>
    <p>Click the new flow to open it.</p>
    <figure class="kb-figure" data-ph="Screenshot: opening the cloned flow">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/e541bbf4-4277-45ba-93be-358a3650d418/action-ecefa60087664a0f9e3fd863ac3ee055_a170d64539284d18a63fc0151679520a_text_export.jpeg" alt="Opening the newly cloned flow" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Opening the copy</figcaption>
    </figure>
  </li>
  <li>
    <p>Rename and configure it as required.</p>
    <figure class="kb-figure" data-ph="Screenshot: renaming the cloned flow">
      <img src="https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-08-25/153c487a-20b8-4a73-b499-6ea58e35c50d/action-d32aaeccb9da40649e97fd4ae0d49f79_c09f80aa814245c58aff5104ac08bbec_text_export.jpeg" alt="Renaming and configuring the cloned flow" loading="lazy" onerror="this.closest('.kb-figure').classList.add('is-missing')" />
      <figcaption>Adapting the copy</figcaption>
    </figure>
  </li>
</ol>
